# iPaddle

**iPaddle** — a classic Arkanoid-style brick breaker built with **SpriteKit** and **SwiftUI**, targeting iPad in landscape orientation. No external dependencies — everything (including sound effects and the app icon) is generated and committed in this directory.

## Opening and running

1. Open `ipaddle.xcodeproj` in Xcode (14 or newer; built against iOS 16 deployment target).
2. Select the **ipaddle** scheme and an iPad simulator (e.g. *iPad Pro 11-inch*), then **Run** (⌘R).
3. To run on a physical iPad: select your device, and in *Signing & Capabilities* pick your Apple ID team (automatic signing). Xcode will handle provisioning.

## How to play

- **Drag** anywhere to move the paddle.
- **Tap** to launch the ball (serves start stuck to the paddle).
- Where the ball strikes the paddle controls the bounce angle — edge hits send it wide.
- Clear all destructible bricks to advance. 8 levels; silver `X` bricks are indestructible.
- 3 lives to start; high score is persisted on device.

### Bricks

| Brick | Hits | Points |
|-------|------|--------|
| Green | 1 | 50 |
| Blue | 2 | 100 |
| Red | 3 | 150 |
| Silver | indestructible | — |

### Power-ups (22% drop chance from destroyed bricks)

| Capsule | Effect |
|---------|--------|
| **E** (blue) | Expand paddle for 12 s |
| **M** (purple) | Multiball — two extra balls |
| **S** (orange) | Slow ball for 8 s |
| **L** (red) | Auto-firing twin lasers for 8 s |
| **+** (green) | Extra life (max 6) |

## Engineering notes

- Logical playfield is 1024×768 with `aspectFit` scaling — letterboxes cleanly on 10.9"/11"/12.9" iPads.
- Physics: zero gravity, restitution-1 bodies; ball speed is re-normalized every frame and a minimum vertical velocity fraction prevents endless horizontal bounces.
- Ball speed scales up per level (470 → 760 pt/s cap).
- Sounds are square/sine-wave WAVs generated by a Python script (`tools` not required at build time); haptics are no-ops on iPads without a Taptic Engine.
- Landscape-only via `UIRequiresFullScreen` + orientation keys in `Info.plist`.
